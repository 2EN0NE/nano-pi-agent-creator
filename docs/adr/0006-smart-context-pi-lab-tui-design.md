## 1. smart-context 面板

**命令：** `/smart-context`
**定位：** 模型路由控制台——查看路由决策、切换 Profile、锁定 Arm。

### 1.1 Tab 1 — 决策记录

```
┌─ Smart Context ──────────────────────────────────────────┐
│   [决策]   状态   配置                                     │
│ ────────────────────────────────────────────────────────  │
│                                                            │
│  轮次  Arm  结果  模型                      详情           │
│  ─────────────────────────────────────────────────       │
│  > #12  C    +1    deepseek/deepseek-v4-pro   r=0 b=0    │
│    #11  T    -1    litellm/leihuo-gpt-5.3     r=1 b=0    │
│    #10  P    +1    deepseek/deepseek-v4-pro   r=0 b=0    │
│     #9  C     0    deepseek/deepseek-v4-flash r=0 b=0    │
│     #8  S    +1    deepseek/deepseek-v4-pro   r=0 b=0    │
│                                                            │
│ ────────────────────────────────────────────────────────  │
│  L 图例 · Enter 展开详情 · Tab 切换 · Esc 关闭             │
└───────────────────────────────────────────────────────────┘
```

**列说明：**

| 列   | 含义                            | 示例                                                                             |
| ---- | ------------------------------- | -------------------------------------------------------------------------------- |
| 轮次 | 会话中的 turn 编号              | `#12`                                                                            |
| Arm  | 策略缩写 (动态从 registry 读取) | C=classifier, T=tree-escalation, P=pure-signals, S=conservative, F=project-first |
| 结果 | 综合评分                        | +1(好) / 0(中性) / -1(坏)                                                        |
| 模型 | 路由到的模型完整路径            | `deepseek/deepseek-v4-pro`                                                       |
| 详情 | 关键信号摘要                    | r=retry, b=bounce, f=fork, c=corrects, cd=continueDepth, e=toolErrorRate         |

**交互：**

- `↑↓` 浏览历史
- `Enter` 展开选中轮的完整信号明细浮层
- `L` 弹出策略缩写图例浮层（动态渲染，从 registry.list() 读取）

**图例浮层：**

```
┌─ Arm 图例 ───────────────────────────────────┐
│                                                │
│  C   classifier        LLM 复杂度分类器        │
│  T   tree-escalation   树复杂度升级策略        │
│  P   pure-signals      纯信号加权策略          │
│  S   conservative      保守策略               │
│  F   project-first     工程文档优先策略        │
│                                                │
│  结果:  +1 好 / 0 中性 / -1 坏                │
│  详情:  r=retry b=bounce f=fork                │
│                                                │
│ ─────────────────────────────────────────────  │
│  任意键关闭                                    │
└────────────────────────────────────────────────┘
```

## 2. pi-lab 面板

**命令：** `/lab`
**定位：** 实验观测台——按命名空间分组，查看实验结论、arm 细节。

### 2.1 顶层布局（两列）

```
┌─ pi-lab ────────────────────────────────────────────────┐
│   [当前会话]   全局                                       │
```

## 附录 A：API 覆盖矩阵

| API 类别      | 函数                                                       | 标注 | 窗口 | 路径 | 快照 |
| ------------- | ---------------------------------------------------------- | ---- | ---- | ---- | ---- |
| **A.Node**    | findByType / findByLabel / findAncestor                    | ✓    | —    | —    | —    |
| **B.Path**    | pathToLeaf / pathBetween / distance / LCA / entriesBetween | —    | —    | ✓    | —    |
| **C.Struct**  | branchCount / maxDepth / treeComplexity                    | —    | ✓    | —    | —    |
| **D.Aggr**    | countByType / compactionHistory / entryTypeTimeline        | —    | ✓    | —    | —    |
| **E.Content** | extractLabels                                              | ✓    | —    | —    | —    |
| **F.Window**  | lastN / entriesSinceLastCompaction                         | —    | ✓    | —    | —    |
| **G.Annot**   | getAnnotations / annotate                                  | ✓    | —    | —    | —    |
| **H.Snap**    | snapshot / diff                                            | —    | —    | —    | ✓    |
| **Retry**     | detectRetry                                                | —    | ✓    | —    | —    |

**覆盖率：19 个生效 API 中 15 个有 TUI 覆盖，3 个可微量扩展覆盖。**
`extractUserMessages` / `detectKeywords` / `toolCallDistribution`(placeholder) 不在 TUI 中——保留给 smart-context 的信号计算使用。

## 附录 B：跨面板关系

```
pi-session-tree               pi-lab                   smart-context
─────────────                 ──────                   ─────────────
提供原始树数据        →       接收 outcome 数据  →      使用 pi-lab 分析结论
提供信号（重试/分支）  →                              决定路由策略
                            提供实验结论       →
                            提供 arm 统计       →      展示在「分析」子 Tab
                            提供 metric 明细    →
                            展示在 pi-lab 面板         展示在「决策」+「状态」Tab
```

三个面板独立入口，不相互跳转。
