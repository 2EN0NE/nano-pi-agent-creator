# permission-gate 阻断确认树与策略管理重构（UX 2.0）

**决策**：将 permission-gate 的拦截确认框从纯文本（`showConfirmDestructive`）重构为**命令树视图**，并将策略管理升级为「算法沉淀 + 手动策略」双轨制；`/permission-gate` 直接进入策略面板（主菜单取消），新增「设置」一级 tab 承载全部配置。

## 阻断确认树（拦截窗口）

- 拦截窗口展示**两层命令树**：根 = 完整命令，叶子 = 拆解的子命令（判定原子 = `BashCommand`，`parseBashCommand` 当前是扁平拆解，不增强 parser 保留嵌套）。子命令多时可折叠。
- 树节点前**颜色小点**提示风险：critical → `error`（红）、warning → `warning`（黄）、info → `accent`（强调）、无风险 → `text`（白）。复用 pi-tui theme，无自定义色。
- **放行语义是整条命令的会话级决策，不改写命令**：放行 = 原命令直接执行；拒绝 = 整条不执行。绝不做部分执行/命令改写（改写后 LLM 原本想做的操作已变，无意义）。叶子级的「添加为策略/加入规则」是粒度更细的管理操作，与本次放行决策相互独立。
- 键位：`↑↓` 树内导航、`←→` 叶子详情 进入/退出、`alt+←→` 折叠/展开（对齐 custom-tree）、`enter` 确认放行、`esc` 拒绝拦截、`a` 叶子「添加为策略」。
- 叶子详情页展示该子命令的风险判断到最小粒度（危险等级 + 命中规则/路径/读写方向）。
- 与外部确认通道（ADR-0028）的竞争机制保持不变（谁先来谁生效，AbortController 关闭未落败的 TUI 框）。

## 沉淀级别与手动策略

- **默认沉淀级别**：新增配置项，默认**会话级**（会话结束失效），用户可在设置中修改。它**只作为手动创建策略的默认选项**；算法沉淀（graduated）仍按 tier→scope 映射（critical→会话 / warning→项目 / info→用户）自动决定层级。
- **手动策略（manual rule creation）**：新增**独立于计数**的显式策略存储（Q8-B）。用户在阻断框对某条子命令按 `a` → 弹级别选择（默认沉淀级别置顶 + 会话>项目>用户顺序，不重复）→ 一步创建精确命令级策略（Q9-C 默认命令级，工具/目录扩展后续在策略面板操作）。手动策略不受阈值调整影响，面板行标记 `手动` / `自动` 区分来源（不带方括号，Q13-A）。判定时手动策略优先于 graduated。
- **层级调整**：策略面板选中规则按 `m` → 弹层级选择（默认当前层）→ **计数迁移**（源层删除、目标层累加），非复制（Q7-A）。
- **graduated 默认开启**：`dynamicPolicyEnabled` 默认 `true`——同一命令确认达阈值后自动放行（无感），解决"反复确认同一命令"痛点。graduated 仍按 tier→scope 决定层级；手动策略（用户拍板）与其并存、优先级更高（Q12-B）。

## 策略面板与设置

- `/permission-gate` **直接进入策略面板**（主菜单取消，Q2a-A）：一级 tab = 会话/项目/用户/历史/分析/**设置**（6 个）。
- **设置 tab**：顶部为高频**开关行**（权限门、动态策略、widget 显示，选中 enter 即切换，不跳页）；低频配置走 master-detail 二级页：拦截模式（patterns）、沉淀级别、阈值/范围、widget 详情（Q14-B）。
- **拦截模式（patterns）管理**：master-detail——`enter` 进入该模式操作页（编辑正则 / 修改级别 / 删除），`a` 新增、`x` 删除（Q3-A）。新增/编辑级别用 critical/warning/info 三选一（Q3a-A）。
- 策略面板底部显示 tier→scope 映射提示（critical→会话 / warning→项目 / info→用户）。

## 为什么（关键权衡）

1. **手动策略独立存储而非复用计数**：用户拍板的信任（显式）与统计推断（graduated 达到阈值）性质不同；独立存储才能区分来源、不受阈值调整影响、独立删除调级。
2. **放行不改写命令**：部分执行会改变命令语义，使 LLM 原本的操作意图失效——拦截窗口只做"看"（树 + 风险）和"管"（叶子级管理），不做"拆"。
3. **graduated 默认开启**：默认关闭导致用户反复确认同一命令（计数累积但从不应邀放行）；tier→scope 安全约束 + 阈值可调使其默认开启可接受。
4. **默认沉淀级别 = 会话级（仅手动创建）**：手动策略是用户明确创建的信任，默认临时（会话级）更符合"临时信任 < 全局信任"的安全心智；算法沉淀的 tier→scope 是统计推断的自动层级，两者职责分离。

## 补充（命中原因解释与清单管理）

- 阻断树详情页由「单条最高分类」升级为「逐条陈列全部命中」，每条带来源标记与解释文案（见 ADR-0025 补充）。
- 设置 tab 新增「危险命令清单 / 权限命令清单 / 路径空间」三个二级页（增删 + 备注编辑）；拦截模式操作页新增「编辑备注」（`a` 新增流程末步输入可选备注）。
