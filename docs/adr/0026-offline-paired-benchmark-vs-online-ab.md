# 离线配对基准（bench）与在线 A/B（pi-lab）的分野

量化插件价值有两种干预形态：**会话内变体**（同一插件的不同参数/策略）与**环境级变更**（装/卸整个扩展）。pi-lab 覆盖前者（在线 A/B + 贝叶斯后验），并已把「扩展开关」明确排除在外（见 CONTEXT.md「能力变体」）。新建 bench 正是为覆盖后者：离线、固定任务 + 固定模型、配对对比（无插件 vs 有插件）。

- **状态**：accepted
- **考虑过的选项**：复用 pi-lab 加一个「离线模式」——否决。pi-lab 的 `select()/record()` 语义绑定会话内臂，装/卸扩展是环境级、非会话内变体，硬塞会污染其信号归因模型。
- **后果**：bench 与 pi-lab 长期共存互补，各自维护。bench 的 config 维度是「装/卸扩展」，pi-lab 的 arm 维度是「会话内参数变体」，两者不可混用。
