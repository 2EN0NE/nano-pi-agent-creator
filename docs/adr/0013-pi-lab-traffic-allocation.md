# pi-lab 分流控制：臂间权重分配，分层互斥与受众定向不预建

**状态**: accepted

分流控制只做臂间分配权重：稳定哈希分桶把哈希空间 `[0,1)` 按 arm 权重切分，落哪个区间分哪个 arm，默认等权。

分层互斥（layering）不预建：TAG 是节点级 + 规则按 `toolName` 匹配，多插件并行时各自产生各自的节点、各自被打各自的 TAG，信号天然隔离，无需会话级互斥。实验名支持命名空间前缀（如 `edit/strategy`）作为未来扩展点。

受众定向不建独立 targeting 引擎：Pi 是单用户本地工具，"谁进实验"由消费方在 `select()` 传入的上下文（contextKey）决定；"分析时按什么切片"由 `query()` 的多维分组过滤（按 label/toolName/model/时间窗）承担。
