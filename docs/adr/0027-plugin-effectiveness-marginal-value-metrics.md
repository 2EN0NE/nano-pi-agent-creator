# 插件有效性 = 边际价值，plugin_triggered 为独立指标

bench 度量的是「有插件 vs 无插件」在同一任务上的**边际价值 delta**（解决率 / token / 成本 / 耗时 / 行为），而非绝对达标或功能正确性。因 nano 有 20 个插件、单插件隔离对比时目标插件可能根本没被 agent 调用，`plugin_triggered` 作为**独立指标**记录：未触发的 cell 不混入 delta、单列触发率。

- **状态**：accepted
- **考虑过的选项**：把「未触发」cell 直接判无效、过滤出统计——否决。因为「插件装上了但 agent 不用」本身是可发现性/可用性问题，是有价值的信号，不该丢弃。
- **后果**：analyze 报告须分层呈现——触发率 + 「触发后的边际价值」。verify.sh 之外需额外探针判定目标插件是否被实际调用。
